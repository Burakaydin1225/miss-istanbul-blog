# Build düzeltmesi

Bu paket iki sorunu düzeltir:

1. `content-presign` yetki kontrolündeki TypeScript `includes()` dar tip hatası kaldırıldı.
2. Blog `ContentType` / `ContentStatus` sabitleri uygulama katmanına alındı; panel doğrudan generated enum export'una bağımlı değil.

Ayrıca eski/stale Prisma generated klasörü paketten çıkarıldı. `npm run build` ve `npm run dev` artık önce `prisma generate` çalıştırır.

Veritabanı migration'ı YOKTUR. `prisma migrate deploy` çalıştırmayın. Mevcut schema/veri değiştirilmez.

Önerilen ilk çalıştırma:

```powershell
Remove-Item -Recurse -Force .next -ErrorAction SilentlyContinue
Remove-Item -Recurse -Force src\generated\prisma -ErrorAction SilentlyContinue
npm run build
```
